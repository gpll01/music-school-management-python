# Music School Management System

## Descrizione

Progetto sviluppato per l'esame di Informatica, con l'obiettivo di realizzare un programma Python per la gestione di una scuola di musica.

Il sistema consente di organizzare corsi, studenti, insegnanti, strumenti musicali e concerti attraverso l'utilizzo della programmazione orientata agli oggetti (OOP).

## Funzionalità principali

- Gestione dei corsi e verifica dei requisiti per l'iscrizione.
- Gestione degli strumenti musicali e delle relative caratteristiche.
- Organizzazione di studenti e insegnanti.
- Assegnazione degli insegnanti ai corsi in base alle competenze.
- Organizzazione dei concerti e gestione dei partecipanti.
- Calcolo della durata totale dei concerti.
- Generazione di report con il numero di iscritti e le percentuali degli studenti per livello di esperienza.
- Individuazione del corso con il maggior numero di iscritti.

## Tecnologie e concetti utilizzati

- Python
- Programmazione orientata agli oggetti (OOP)
- Classi, oggetti e metodi
- Ereditarietà
- Liste e strutture dati
- Cicli e condizioni
- Elaborazione e calcolo di dati

## Obiettivo didattico

Applicare i principali concetti della programmazione Python alla realizzazione di un sistema gestionale, simulando un contesto concreto attraverso la modellazione di entità e delle loro relazioni.
